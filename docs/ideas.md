# Ideas

灵感收件箱。新想法先记这里，**不要直接进 active plan**。

## 格式

```markdown
- [ ] (P1) 简述 — Why: 一行原因
  - 来源：YYYY-MM-DD 会话 / 触发原因
  - 状态：idea | planned | in-progress
```

实现后用 checkbox + 计划链接表示完成，不删除条目：

```markdown
- [x] (P1) 简述 — Why: ... [→ plan-YYYY-MM-DD-slug]
```

## 优先级

| 标记 | 含义 |
|---|---|
| P0 | 必须做 |
| P1 | 应当做 |
| P2 | 想做 |
| P3 | 探索性 |
